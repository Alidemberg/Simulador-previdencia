# ⚡ Simulador de Aposentadoria Especial

Simulador interativo baseado na decisão do STF (ADI 6309, 03/06/2026) que derrubou a idade mínima para aposentadoria especial.

## Funcionalidades

- **Aposentadoria Especial** — calcula coeficiente, valor e projeção acumulada
- **Especial vs. Comum** — compara as duas modalidades por expectativa de vida
- **Progressão do Benefício** — visualiza o crescimento ano a ano de 60% a 100%
- **Ponto de Equilíbrio** — descobre a partir de qual idade compensa antecipar

## Como rodar localmente

```bash
npm install
npm run dev
```

## Deploy

Projeto configurado para deploy automático na Vercel.
